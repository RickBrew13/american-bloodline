# Source register — Lucy Jane Price Carman Estes

Date reviewed: 28 November 2026

Each item below is a public compiled profile or index unless explicitly described otherwise. Original records are not implied by a tree/profile citation.
- [FamilySearch public Lucy Jane Price profile (KN3Y-MRJ)](https://ancestors.familysearch.org/en/KN3Y-MRJ/lucy-jane-price-1882-1959) — Compiled profile reports birth 21 October 1882 in Owen County, marriage to Roscoe Carman 23 December 1902 in Casey County, parents Nathanial Price and Martha Ellen Stephens, and nine children. It lists census, obituary-index, and Kentucky county-marriage sources, but those underlying records were not reviewed here.
- [FamilySearch public Nathanial Price profile (KN3V-FN2)](https://ancestors.familysearch.org/en/KN3V-FN2/nathanial-price-1846-1935) — Compiled profile lists Martha Ellen Stephens as spouse and eight children including Lucy Jane, and identifies Nathanial’s parents as Franklin Price and Sarah Margaret Lynn. It gives Nathanial and Martha dates that differ from the Find a Grave-derived dates currently shown in Lucy’s parent card; parent card left unchanged.
- [FamilySearch public Martha Ellen Stephens profile (KN3Y-MPQ)](https://ancestors.familysearch.org/en/KN3Y-MPQ/martha-ellen-stephens-1847-1925) — Compiled profile identifies Nathanial Price as spouse and lists eight children including Lucy Jane; it gives Martha dates about 13 March 1847–12 June 1925, while the existing profile card follows the Find a Grave variant 1848–1926. Discrepancy retained, existing parent card unchanged.
- [FamilySearch 1920 Kentucky marriage index entry for Lillie May Carmen and William P. Henry (record Q2Q6-KKCQ)](https://www.familysearch.org/ark:/61903/1:1:Q2Q6-KKCQ) — Saved project audit records a transcript for Lincoln County, 1 June 1920, record no. 102, naming Roscoe Carmen and Lucy Carmen as Lillie’s parents. This supports the parent link under a Carman/Carmen spelling variant; the original schedule was not visually inspected.
- [FamilySearch public Nathaniel Price profile (KN3V-FN2 spelling variant)](https://ancestors.familysearch.org/en/KN3V-FN2/nathanial-price-1846-1935) — The FamilySearch page spells the father’s name Nathanial, while the current Lucy profile and Find a Grave use Nathaniel. Retain both source forms; no name correction made.
- [FamilySearch Lucy Jane Price namesake profile (L2SB-7Q2)](https://ancestors.familysearch.org/en/L2SB-7Q2/lucy-jane-price-1882-1952) — A different public profile search result gives Lucy Jane Price a 20 August 1882 birth in Webster, Kentucky, and a 1952 death. No source links her to Roscoe or to Nathanial and Martha; do not merge with this Lucy.
