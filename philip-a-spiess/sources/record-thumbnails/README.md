# FamilySearch-attached source image thumbnails

Small image thumbnails attached to public FamilySearch tree profiles are archived here as source references. They are low resolution, may not display all record details, and are not treated as a complete transcription or independently reviewed original. The originating public profile and the attached record type are described for each file.
