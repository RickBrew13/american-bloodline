## Grading key
- ✅ **VERIFIED** — primary record(s) seen (birth/marriage/death/census/directory)
- 🔶 **CORROBORATED** — strong secondary + primary support converging
- 📜 **SWORN** — sworn testimony, primary source but uncorroborated (Mary Catherine's 1907 application)
- 🟡 **RECONSTRUCTION** — sourced reconstruction (Gough's GPS-aspiring work citing records)
- ⚪ **SINGLE RECORD** — exactly one record names the link
- 📖 **BOOK-LEVEL** — book and/or Geni only; no record yet seen
- ❓ **UNKNOWN / UNPROVEN** — no evidence; line stops here unless noted

**Generation numbering:** Rick = G0. Parents = G1. Grandparents = G2. Great-grandparents = G3. 2nd great = G4. 3rd great = G5. 4th great = G6. 5th great = G7. 6th great = G8.
